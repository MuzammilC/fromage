# Phase 1 validates the Judge against a synthetic Calibration Set

There is no openly licensed, CEFR-labelled corpus of spoken learner French. The only available rater is the developer, at A2, who cannot reliably separate Band 2 from Band 3. Paying a certified examiner is outside the budget.

So Phase 1 measures the Judge against a Calibration Set instead: scripted answers with a known Intended Band, plus Degradations. The metrics are:
- whether the Judge orders the Bands correctly,
- whether repeated Judgements agree with each other,
- bias from answer length, paraphrase, and synthetic versus human voices.

Phase 1 claims "measured sensitivity and consistency", never "agreement with human examiners". The harness accepts a human-rated Gold Set as soon as one exists.
