# Original content only; neutral branding

FEI forbids reusing DELF/DALF subjects, and the press extracts in its sample papers belong to third parties. So no official Item text is ever shipped. Every Item is original: generated against the Topic Taxonomy, checked for n-gram overlap with FEI text, and reviewed before publishing. The judge prompts paraphrase the Grid descriptors instead of quoting them.

The product is branded "Fromage: French Language Assessment Prep". Each Exam Definition is described only as a fact ("A2 speaking mock, DELF format"). A footer states "Not affiliated with France Éducation international", and every Report says the Estimated Score is an estimate, not an official result.
